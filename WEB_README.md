# Project P.I.T.T. Web

Готовая сборка Godot 4.7.1 (WebAssembly / WebGL 2) находится в dist/. Серверная логика не требуется. Для локальной проверки: python -m http.server 8080 --directory dist, затем http://localhost:8080. Открытие HTML через file:// не поддерживается.

Сохранения хранятся в IndexedDB браузера. Автосохранение — раз в минуту активной игры. Перед закрытием нажмите «Сохранить» и дождитесь подтверждения. «Скачать сохранения» создаёт резервную копию всех слотов и настроек. Для восстановления выберите «Загрузить сохранения» в главном меню, затем обновите страницу. Данные привязаны к браузеру и адресу сайта; между устройствами автоматически не синхронизируются.

После сообщения «Офлайн-кэш готов» сайт можно повторно открыть без интернета. Очистка данных сайта может удалить и кэш, и сохранения; делайте резервные копии.

Workflow .github/workflows/pages.yml публикует dist/ при push в main. В Settings → Pages выберите GitHub Actions. Все пути относительные; специальные заголовки COOP/COEP не нужны. Общий размер — около 140 МБ; каждый файл меньше 100 MiB. GitHub Pages бесплатен для публичных репозиториев, мягкий лимит трафика — 100 ГБ/месяц: https://docs.github.com/en/pages/getting-started-with-github-pages/github-pages-limits

Steam Overlay, Steam Cloud и достижения Steam недоступны. Объёмный туман Forward+ отключён для совместимости с WebGL. Для захвата мыши используйте отдельную вкладку обычного браузера.

После Esc кликните левой кнопкой по игровому полю, чтобы снова скрыть курсор и управлять обзором. Клик для возврата управления не использует предмет. В меню, на паузе и в окне улучшений курсор остаётся свободным. После обновления сайта перезагрузите страницу для получения исправления.

Регрессионные проверки захвата курсора: `node --test tests/mouse-capture.test.cjs`.

Локально проверены запуск уровня, сохранение, загрузка после обновления страницы, экспорт/импорт резервной копии и офлайн-запуск. Полное прохождение, поздние этапы и мобильные браузеры не проверялись. В репозитории размещена готовая сборка; исходный архив, восстановленный проект и инструменты сборки хранятся отдельно у владельца.
