# CloverSecret

Браузерная версия Project P.I.T.T. — статический сайт без игрового сервера.

GitHub Pages: https://demosand.github.io/CloverSecret/

Нажмите «Загрузить и играть». Первая загрузка — около 140 МБ. Управление: клавиатура и мышь. Прогресс сохраняется в браузере; доступны резервные копии и офлайн-кэш.

В `dist/` находится готовая сборка. Workflow `.github/workflows/pages.yml` публикует эту папку при push в `main`. В Settings → Pages выберите источник **GitHub Actions**.

Подробности: [WEB_README.md](WEB_README.md).
